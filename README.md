A simple and intuitive 2D Tower Defense game built to showcase core gameplay mechanics, pathfinding, and strategic wave-based progression.

## Features

- **Strategic Placement:** Place different types of defense towers to block enemy paths.
- **Enemy Waves:** Face progressively difficult waves of enemies with unique attributes (speed, health).
- **Resource Management:** Earn gold by defeating enemies to buy new defenses.
- **Dynamic Pathfinding:** Enemies find the optimal path to reach your base.
